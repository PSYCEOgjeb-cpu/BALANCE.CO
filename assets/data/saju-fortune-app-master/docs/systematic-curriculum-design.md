# 명리학 체계적 학습법 기반 커리큘럼 설계

## 🎯 학습 철학과 접근법

### 핵심 원칙
- **장기적 정진**: 최소 5-10년의 체계적 학습 여정
- **학문적 깊이**: 단순 점술을 넘어 삶의 패턴을 탐구하는 학문으로 접근
- **균형잡힌 관점**: 이론과 현실의 조화, 운명론이 아닌 자기이해의 도구
- **실용적 지혜**: '인생의 조언자'로서 성장하는 것이 최종 목표
