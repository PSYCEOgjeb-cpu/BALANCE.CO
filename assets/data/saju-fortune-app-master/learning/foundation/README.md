# 사주 명리학 기초 학습 모듈

## 📱 PWA (Progressive Web App) 개발 프로젝트

사주 명리학의 기초 개념을 학습할 수 있는 모바일 최적화된 웹 앱입니다.

### 🎯 학습 내용

- **음양 (陰陽)**: 음과 양의 기본 개념과 특성
- **오행 (五行)**: 목(木), 화(火), 토(土), 금(金), 수(水)의 상생상극 관계  
- **천간지지 (天干地支)**: 10간과 12지의 의미와 활용
- **퀴즈**: 학습한 내용을 확인하는 인터랙티브 퀴즈

### 🚀 서버 실행 방법

PWA 기능을 제대로 테스트하려면 HTTP 서버를 통해 실행해야 합니다.

#### 1. Python 서버 사용 (권장)

```bash
# 기본 실행 (포트 8000)
python server.py

# 다른 포트로 실행
python server.py 3000

# HTTPS 모드로 실행 (개발용)
python server.py 8000 https
```

#### 2. 브라우저에서 접속

```
http://localhost:8000
```

서버 실행 시 자동으로 필요한 아이콘들이 생성됩니다.

### 📁 프로젝트 구조

```
foundation/
├── index.html          # 메인 HTML 파일
├── styles.css          # 기본 스타일시트  
├── mobile-styles.css   # 모바일 최적화 스타일
├── script.js           # 인터랙티브 기능
├── manifest.json       # PWA 매니페스트
├── service-worker.js   # 서비스 워커
├── server.py           # 개발용 HTTP 서버
├── icons/             # 앱 아이콘들
└── README.md          # 이 파일
```

### 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **PWA**: Service Worker, Web App Manifest
- **개발서버**: Python HTTP Server
- **아이콘**: SVG (자동 생성)

### 🔧 개발 환경 설정

1. **파일 다운로드**: 모든 프로젝트 파일을 로컬에 저장
2. **Python 확인**: Python 3.x 설치 확인
3. **서버 실행**: `python server.py` 명령 실행
4. **브라우저 테스트**: `http://localhost:8000` 접속

### 🐛 문제 해결

#### Service Worker 오류
- ❌ `file://` 프로토콜에서는 서비스 워커 작동하지 않음  
- ✅ HTTP 서버 (`python server.py`)를 통해 접속 필요

#### 아이콘 파일 없음
- ✅ `server.py` 실행 시 자동으로 SVG 아이콘 생성
- 📁 `icons/` 디렉토리에 아이콘 파일들 자동 생성

#### 모바일에서 테스트
- 📱 같은 네트워크의 모바일 기기에서 접속: `http://[컴퓨터IP]:8000`
- 🔍 컴퓨터 IP 확인: `ipconfig` (Windows) / `ifconfig` (Mac/Linux)
